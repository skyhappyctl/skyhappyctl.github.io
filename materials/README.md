# 可公开学习资料

本目录只存放已经筛选的课件、作业、笔记和实验源码，按课程 ID 和类型分组。

资料清单在上级 `materials-data.js` 的 `courses[].resources` 修改。请先放入文件，再追加标题、类型、相对路径、`public: true` 和可选的 `bytes` 文件大小。

实验源码 ZIP 是重新筛选打包的文件，不含原始提交包、数据集、模型权重、视频或编译缓存；课程实验中少量必要的测试向量可能保留。源码包不承诺无需外部数据／环境就能运行。

私人文件、待复核扫描件和本地检查清单应留在网站目录外。公开仓库即使不在网页列出的文件也能被访问。正式发布前仍需人工检查隐私与课程分享许可。

详情见 [学习资料使用指南](../学习资料使用指南.md) 和 [学习资料导入说明](../学习资料导入说明.md)。
