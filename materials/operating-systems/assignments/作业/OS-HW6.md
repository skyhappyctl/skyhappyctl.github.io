## Q4

页面大小为2KB，程序执行时系统只分配了1个页框。

* 程序A

````c
int a[256][256];
int i, j;
for(i = 0; i < 256; i++)
    for(j = 0; j < 256; j++)
        a[i][j] = 0;
````

二维数组a\[256][256]每行所占字节数为：256*4=1024字节，每一页是2KB=2048个字节，因此每个页面可以容纳2行数组，数组a占128个页面。因为程序A其循环是对数组逐行扫描，每个页面会缺失1次，故缺失128次。



* 程序B

````C
int a[256][256];
int i, j;
for(j = 0; j < 256; j++)
    for(i = 0; i < 256; i++)
        a[i][j] = 0;
````

二维数组a\[256][256]每行所占字节数为：256*4=1024字节，每一页是2KB=2048个字节，因此每个页面可以容纳2行数组，数组a占128个页面。因为程序B其循环是对数组逐列扫描，每一列都会导致缺失1次，故缺失256\*128=32768次。



## Q5

````C
int X[N];
int step = M;	//M is some predefined constant
for(int i = 0; i < N; i += step)	X[i] = X[i] + 1;
````

a)	

如果该程序运行在页面大小4KB=4096B，且有64个TLB表项。初始时TLB表中还无缓存页，因此欲使得循环的每次执行都会导致TLB缺失，每次访问递增的内存地址必须不小于 4096，故$step=M=4096/4=1024$，$N>1024$即可。



b)

若循环重复多次，TLB 会逐步缓存曾访问过的页（如 0,64,128,…）。那么当64个TLB表项均被缓存后，循环重复时将不再发生缺失，因此，除了$M=1024$之外，还需使得数组的大小大于4KB\*64=256KB，因此$N\ge256KB/4B=65536$。
